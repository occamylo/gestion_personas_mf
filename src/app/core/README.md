# core

Lógica transversal singleton de `agora-gestion-personas-mf`. Se provee una sola vez en la
aplicación y **nunca** se importa en módulos de dominio.

- `_guards/` — guards de rutas
- `constants/` — constantes globales
- `interceptors/` — interceptores HTTP
- `managers/` — orquestadores de estado/negocio
- `services/` — servicios de datos/API
